用户要求按本会话验证过的方向升级并作为稳定版使用。

采纳：
- 新增 kind: rules 与 rules.py。规矩清单是一个片段，每次修改追加完整新版本并 supersedes 上一版；只提供逐行操作（add / edit --match / remove --match），整份替换只用于初次建立与合并分叉。每次修改必须写 why。维护测试中三个 agent 都自发选择精确替换，零误差。
- --for-agent 输出：规矩清单 + 未完成目标 + 最近判断标题 + 查阅方法。尚未建立清单的项目回退到原有的原则与在force判断列表，并提示建立清单，避免未迁移项目开机失明。
- doctor 只做结构检查：删除 unexplained-change、capture 祖先/分叉、invalid-explanation；新增 rules-fork、rules-malformed。门禁曾在 sulacompany 产出 120 条凑数记录。
- 删除：finish.py、scheduler.py、llm-dispatcher.py、auto-update-from-canonical.py、hooks/install.py、principles/ 分发；视图 digest/progress/thread/family/principles/unexplained/decay 与 --focus；note.py 的 --explains 与 --verify-path；verifier-shell 的版本绑定。
- 保留：witness.py + capture.py 作为非 git 文件夹的可选证据工具，不进门禁；migrate.py 的 legacy 迁移路径不动，以减少本次改动面。
- 更新路径会删除已退役的工具文件，以及本工具曾安装的 post-commit 与 Kiro 触发器（仅限内容可确认是本工具写入的）。

旧片段全部继续可解析，含已不再使用的字段，故按本项目版本规则为 v1.4 而非 v2.0。
