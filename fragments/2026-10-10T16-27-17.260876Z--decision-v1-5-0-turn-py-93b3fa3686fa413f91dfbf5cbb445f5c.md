用户批准并要求直接作为新稳定版发布，不再逐项给用户验证。
采纳：每轮结束 agent 把用户原话和回答原文经 stdin 交给 tools/sula_vector/turn.py；turn.py 按秘密的形状脱敏，追加 kind=transcript 片段，打印回执 `[sula] turn recorded (…)`，带 --since 时接着打印本场的判断变更块。回执就是用户在任何宿主里的证据：没有这行就是没记。
本地保证：turn.py 在项目 .gitignore 写入 `fragments/*--transcript-*`（无 git 也写，防止日后 git init 收进去）；git check-ignore 显示仍会被跟踪时拒绝本轮并报错。判断与规矩照旧随 git，原文只在本机。
视图：transcript 不进开机、journal、changes-summary；开机只提示条数和 grep 方法。note.py 拒绝 --kind transcript，保证每份原文都经过脱敏。不解析任何宿主日志；宿主钩子可作喂入者，未验证、非依赖。
约定版本 1.3→1.4（读者必须把 transcript 排除在开机之外）。收尾规矩由“有追加才展示变更块”改为“每轮运行 turn.py 并展示其完整输出”。
